## レビューで範囲外とされた動作への判断

以下は実装済みと扱わず、次段階で必ず検証する。レビューの見送りを製品要件の削除と解釈しない。

1. 古い非同期経路結果と次の曲がり角の判定: 呼び出し元の責任を維持。現在のrouteIDとの照合がなければ、案内がリセットされて連呼するリスクがある。
2. 案内距離と位置精度の閾値: 初期値として維持。実走検証なしでは交差点で早過ぎる・遅過ぎる案内になるリスクがある。
3. 音声の完了・割り込み・バックグラウンド・状態の永続化: 次のアプリ側で実装。現在のイベント発行のみでは案内が実際に聞こえる保証はない。
4. 訪問済み地点の除外: 将来の旅程側で進捗を管理。未対応のまま接続すると、立ち寄り済み地点へ戻る経路になるリスクがある。
5. 実経路生成・快適さの順位付け・道路属性の確認・理由や緩和案の表示: 経路サービスと画面側の責任。現在の選別だけでは走りやすさを最適化できない。
6. 地図・オフライン・スポット・宿泊旅・共有・プライバシー: 後続の段階へ割当済み。このライブラリ単独を完成アプリとして扱うと、ユーザーが必要とする機能が欠ける。
