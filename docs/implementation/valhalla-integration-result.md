# Valhalla接続の検証 — 2026-09-29

## 実装

MapKit表示/地点検索を維持し、Valhalla要求・応答を共通PlannedRouteへ変換。
車種road/hybrid/cross、道路/坂/悪路設定、候補比較、遠回り上限、手動読み上げを接続。
路面unknownは保持。車種/好み変更で旧結果を無効化。部分失敗は警告する。
HTTPS接続先を開発設定から注入し、デフォルト未設定。自動車へのフォールバックなし。
認証情報入りURLを拒否、リダイレクト禁止、キャッシュ/クッキー無効、1.1秒間隔の要求枠を確保。
非数・巨大な時間による表示クラッシュも回帰テストで検出・修正した。

## サーバーの条件

[Valhalla公式](https://valhalla.github.io/valhalla/#demo-server)が公開デモとfair-useを案内。
[運営側の利用要約](https://routing.openstreetmap.de/about.html)は最大1要求/秒、識別子、帰属、地図修正リンク、重い利用をしないことを記載。
全文のドイツ語ページはアクセス拒否のため未取得。公開された公式要約に従い、2区間の開発検証に限定した。
リクエストはサーバーログに保存され得る。本番公開には提供元との調整か自前/管理サービス配備が必要。
